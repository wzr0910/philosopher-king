# 哲人王 · A Tale of Philosopher Kings

一款纯静态、零依赖、零构建的网页文字策略小游戏。
你在博物馆的「哲人王特展」前触到王冠，下一刻已端坐王座——在十二轮国事抉择中，
听取六位哲人顾问的建言，于民心、财富、稳定、自由之间权衡，走向属于你的结局。

## 玩法

- 共 **12 轮**随机国事事件，每轮可听取在场哲人的建议并采纳其一。
- 四维属性 **民心 / 财富 / 稳定 / 自由**（0–100）实时变化，极端走向会即时触发结局。
- **六位哲人顾问**：柏拉图、马基雅维利、老子、霍布斯，以及满足特定条件才会现身的孔子、卢梭。
- 多结局（即时结局 + 结算结局 + 中庸兜底）、成就金印、哲人图鉴、三个本地存档槽。

## 运行

纯静态页面，**无需安装、无需构建**。

- 最简单：直接用浏览器打开 `index.html`。
- 推荐（避免个别浏览器对 `file://` 的限制）：在本目录起一个静态服务器，
  例如 `python -m http.server 8000`，然后访问 `http://localhost:8000/`。

## 部署到 GitHub Pages

1. 将本仓库推送到 GitHub。
2. 仓库 **Settings → Pages → Source** 选择 `main` 分支根目录 `/ (root)`，保存。
3. 稍候即可通过分配的 `https://<用户名>.github.io/<仓库名>/` 访问。

所有资源均为相对路径引用，clone 后或 Pages 子路径下均可直接运行。

## 目录结构

| 文件 | 说明 |
| --- | --- |
| `index.html` | 唯一入口与全部界面结构 |
| `data.js` | 游戏数据：哲人、事件、结局、成就（`window.GAME_DATA`） |
| `engine.js` | 纯逻辑：数值结算、事件抽取、结局/成就判定（`window.Engine`） |
| `game.js` | UI 控制器：渲染、交互、存档、音效接线 |
| `audio.js` | WebAudio 音效与静音/音量（`window.Sfx`） |
| `styles.css` | 全部样式（含响应式与减弱动效适配） |
| `assets/` | 场景图、结局图、成就图、哲人立绘、图标等资源 |
| `check_assets.py` | 资源完整性校验脚本 |

## 资源校验

新增/修改事件、结局、成就或哲人后，运行：

```
python check_assets.py
```

它会逐一断言事件图、结局图、成就图与立绘是否齐备，并报告孤儿结局图；全部通过退出码为 0。

## 字体与隐私

- 英文标题字体 **Cinzel** 通过 Google Fonts CDN 加载；离线或 CDN 失败时自动降级为本地衬线字体。
- 除此之外**无任何后端、网络请求、统计或追踪**；存档与偏好仅保存在浏览器 `localStorage`，清除浏览器数据即重置。
